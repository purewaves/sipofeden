# 🧃 Sip of Eden - Organic Juice E-commerce Platform

A modern, full-stack e-commerce platform for organic cold-pressed juices with AI-powered customer support, real-time analytics, and subscription management.

## ✨ Features

### 🛒 **E-commerce Core**
- Product catalog with advanced filtering
- Session-based shopping cart
- Complete checkout process
- Order management system

### 🤖 **AI-Powered Support**
- 24/7 smart chat assistant
- Personalized juice recommendations
- Customer preference learning
- Health-focused advice

### 📊 **Business Intelligence**
- Real-time analytics dashboard
- Sales tracking and insights
- Customer behavior analytics
- Inventory management

### 📱 **Mobile-First PWA**
- Progressive Web App capabilities
- Offline functionality
- Push notifications
- Mobile-optimized design

### 🔔 **Real-time Features**
- Admin push notifications
- Live order tracking
- Instant cart updates
- Real-time analytics

### 🔄 **Subscription Management**
- Weekly and monthly plans
- Automated renewal reminders
- Delivery scheduling
- Customer retention system

## 🚀 **Quick Start**

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm start
```

### Database Setup
```bash
npm run db:push
```

## 🔧 **Tech Stack**

### Frontend
- **React 18** with TypeScript
- **Tailwind CSS** for styling
- **Radix UI** components
- **React Query** for state management
- **Wouter** for routing

### Backend
- **Node.js** with Express
- **SQLite** database
- **Drizzle ORM** for database operations
- **Session-based authentication**

### AI & Analytics
- **Anthropic Claude** for chat assistant
- **Custom analytics engine**
- **Real-time data processing**
